JRB OS 刷机工具

小纸 Read Pico（ESP32-S3 · 16 MB Flash）· 使用 Edge / Chrome 的 Web Serial 直接在浏览器里刷入，无需安装任何软件

⚠️ 首次刷入必须整表刷写
本固件使用双槽 A/B 分区表，与板厂出厂分区表不同。 所以必须同时写入 bootloader / partitions / boot_app0 / firmware 四部分。
只写应用（app-only）会因分区偏移不同而失败或无法启动。
⚠️ 这是 v0.1.0 预发布版，从未在真机上验证过
体积数据是实测的，但运行时行为未经验证。其中一个已知风险：内嵌中日韩字库被改成了 DEFLATE 压缩 （省 471 KB），而上游刻意不压缩它，因为历史上真机出现过 FontDecompressor std::bad_alloc 崩溃。
如果刷完出现反复重启或翻页崩溃，请回退到官方固件：本工具第一步的「完整备份」就是为此准备的。

步骤 1 · 完整备份（强烈建议）

刷机前先把设备当前的 16 MB Flash 完整读出来存成文件。万一新固件有问题，可以整表刷回去。

尚未备份

备份会把 16 MB 全部读出并通过浏览器保存为 readpico-backup-16MB.bin，大约需要 1–3 分钟。
如果你已经有备份，或者不介意风险，可以跳过这一步直接到步骤 2。

连不上设备？

  1. 用 Edge 或 Chrome 桌面版（版本 89+）。Firefox / Safari 不支持 Web Serial。
  2. 用能传数据的 USB-C 线。很多线只能充电，认不到设备。
  3. 把设备进入下载模式：
    设备完全断电 → 按住电源键不松 → 插入 USB 线 → 保持按住约 3 秒后松开。 屏幕可能保持黑屏或停在启动画面，这是正常的。
  4. 关掉占用串口的程序：Arduino IDE 串口监视器、PlatformIO 监视器、其它刷机页面、串口调试助手。
  5. 换一个 USB 口（优先接主板直出的口，不要用前置面板或 Hub）。
  6. 在设备的弹窗里，选中的端口通常叫 USB Serial Device 或 USB JTAG/serial debug unit。
如何回退到官方固件

如果你做过步骤 1 的备份，回退很简单：用命令行整表刷回备份文件。

esptool.py --chip esp32s3 --port COMx --baud 921600 write_flash 0x0 readpico-backup-16MB.bin

这个网页工具目前只做「写入」，不做「整表恢复」（16 MB 写入在浏览器里太慢且容易中断）。 恢复请用命令行，更可靠。

刷完之后

  1. 拔掉 USB，再重新开机（不要直接按复位键，让它走完整启动流程）。
  2. 确认语言列表只有中文 + 英文，首页不再有「应用」入口，微信读书入口消失。
  3. 确认设置里还留着「SD 卡固件更新」（这是唯一的 OTA 途径）。
  4. 中文显示：内嵌了 3500 常用字，常用字可直接显示；生僻字需要 SD 卡字库。
  5. 重点验证：打开一本中文书，连续翻 200 页；反复切换字号 12↔14↔16↔20。 这一步是为了验证压缩字库是否稳定。
  6. 开一本带 DRM 的 EPUB，确认仍能解密（验证加密模块没被误删）。

遇到问题请到 GitHub Issues 反馈，附上技术日志。
